## How I work

- **Spec-driven, AI-native development.** Requirements live in the repo. I use Claude Code and GitHub Spec Kit to go from spec to working prototype, then hand a validated direction to engineering.
- **Evals before scale.** For AI features, I define what "good" looks like, what the agent may do on its own, and what must always go to a human, before rollout.
- **Prototype to validate or kill.** Building is cheap now. Choosing what to build is the job.
